## 发现与处理

1. **原生报表首次打开后不自动显示结果。** 车型销量、访问趋势、渠道转化会先返回“正在刷新”，后台完成后页面仍保持首次状态。服务器只读核实：车型快照 153 行、访问趋势 31 行，均已成功；近一小时没有失败队列任务。为这三个页面增加每 3 秒取回一次的有限自动更新，最多 20 次，数据到达即停止，不并发，离页停止，切换店铺/周期重置；超时提供重试。服务端渲染不启动浏览器请求。加载中的车型统计使用破折号，避免误显示 0 辆。
2. **应用导航分类不一致。** 买家秀评价、Instagram 列表/展示组及学生优惠顶部导航从“店铺设置”改为“应用中心”。
3. **商品表头挤压。** “变体”标题禁止断行。
4. **少量枚举未中文化。** 经营分析补充部分付款、授权、作废、重新入库；设备补充游戏主机、智能电视。

5. **SEO 无数据被误判为落后。** 所选月份没有日数据或工作记录时，统一显示“暂无数据”，不生成高风险/达标判断；已有真实零值记录仍参与正常计算。
6. **同步和 Webhook 时间不一致。** 后端查询补齐店铺时区字段，列表与详情直接按各行所属店铺时区显示，移除按时间字符串映射店铺的易冲突方式。
7. **系统默认时区空白。** 下拉列表补充已允许保存的 UTC 选项。

这些修复已同时保存在本地开发源码及 `tmp/production-release-20260905/` 合并候选，不能用开发根目录覆盖正式服完整源码。新增 5 项自动加载回归检查已在测试服务器通过，完整候选前端构建通过。测试服最终版本为 `decoadmin-app:page-audit-20260905-r2` / `decoadmin-nginx:page-audit-20260905-r2`。浏览器复查通过后，正式服已更新为 `decoadmin-app:page-audit-20260905` / `decoadmin-nginx:page-audit-20260905`；App、Nginx、Horizon、Scheduler 已切换，公网健康检查通过。
