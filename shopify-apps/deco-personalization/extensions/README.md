# Extensions

- `app-home`: verifies Shopify identity and opens the store-scoped DecoAdmin workspace.
- `recommendations`: Theme App Extension App Block for homepage, product-page, and cart-page recommendations, plus the guarded Smart Cart App Embed. Smart Cart binds one DecoAdmin strategy and renders one eligible product at a time with image, variant, minimum quantity, optional discount pricing, and native-cart fallback.
- `checkout-trust-badges`: movable Checkout UI Extension block for merchant-configured trust information.
- `checkout-recommendations`: movable Checkout UI Extension block that reads a configured Collection and advances through non-repeating, Market-available offers.
- `web-pixel`: strict-sandbox, analytics-consent Web Pixel for anonymous P0 recommendation and checkout events.

All are Test-first source projects. This directory contains no Local or Production Shopify configuration and does not install or activate a theme block or Web Pixel by itself.
