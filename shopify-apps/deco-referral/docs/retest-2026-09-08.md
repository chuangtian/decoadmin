# Referral 第二轮复测与手册核查

范围：仅 macfox-test-app.myshopify.com 和 DecoAdmin staging。生产及其他店铺未操作。日期为 2026-09-08。

## 本轮发现并修复

1. 门户付款偏好没有按已保存值选中，银行资料保存后页面可能仍显示 PayPal。已修复回显及校验错误后的输入保留；真实 HTTPS 保存银行偏好并刷新验证通过，测试后恢复原资料。
2. 邀请链接中的片段令牌会在打开后从地址栏移除，字段校验失败返回页面时无法继续提交。已保留本次表单的令牌、网站及说明，修正字段后可再次提交；单次使用及过期限制保留。真实 HTTPS 错误提交、纠正、接受和重复接受拦截通过。
3. 首次点击或优惠码胜出的情况下，审核快照里的 source_click_id 可能仍来自最后一次其他点击。归属本身未变，但证据可能不一致。现随实际选中的点击记录；优惠码胜出时只关联同一成员的点击。三种模式测试通过。
4. Shopify 应用首页仍有上一阶段“尚未完成全部测试”的固定文字，改为当前测试范围及后台管理提示。

## 测试脚本自身修正

- 格式化工具把启动 Kernel 改为短类名，原 use 位置在启动语句之后，导致门户验收脚本无法启动。已把 use 声明移至启动前，实际 HTTPS 验收随后通过。
- 新增优惠码验收脚本最初误读 codeDiscountNode，应读取 codeDiscountNodeByCode。修正后实际三类生命周期全部通过，并非业务创建失败。
- 自动审批拒绝过恢复阶段同步全店优惠码，已缩小到仅本轮新建的合成码；未执行被拒绝的批量操作。

## 使用手册核查

桌面 Deco 中的《DecoReferral插件使用手册_2026-09-08.docx》更新至 1.1：

- 补充 Shopify 首页“打开 DecoAdmin 后台”和“重新连接”。
- 明确三种模式下有效推荐码仍优先，首次/最后点击用于无有效代码的情况。
- 补充收款方式保存后刷新核对，邀请字段错误后可修改重试。
- 补充 Shopify 订单 ID 获取位置与允许格式，区分展示编号、ID 和网址。
- 补充顾客结账实际应用推荐码的步骤。
- 补充 Shopify 商品行退款/取消后在插件核对佣金及奖励的步骤。
- 补充已有优惠码时免运费与商品折扣不能直接互换，需新计划。
- 补充设备时区、排期状态、异步同步及登录发送频率。

原手册已覆盖业务通知模板与登录邮件的区别、邮件服务需管理员配置、付款凭证限制、CSV 表头及限制、奖励资格、结算负余额和权限。上述不是遗漏，保留其说明。

跨设备增强继续按用户决定暂不开发；没有依据不猜归属。自动转账、A/B、未来高级功能不纳入已实现范围。
